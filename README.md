
# Global Safety Website

A custom, conversion-focused website for [Global Safety](https://globalsafety.us).

## What is included

- A motion-led homepage with an interactive readiness reveal
- Program pages for First Aid/CPR & AED, Threat Ready Survival, Safety Dragons, and Emergency Preparedness
- Pages for audiences, about, FAQs, contact, privacy, and accessibility
- Responsive layouts, reduced-motion support, keyboard-accessible interactions, and social sharing artwork
- A static production build containing 15 routes

## Local preview

Use Node.js 22.13 or newer:

```bash
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Validate the production build

```bash
npm run build
npm test
```

The generated site is written to `dist/`.

## Brand direction

The visual system uses Global Safety's navy, electric-lime, cyan, and off-white palette. Motion is purposeful and focused on preparedness rather than decoration. Original hero artwork was created specifically for this project.

## Important

The existing live site at `globalsafety.us` is not changed by this repository. Domain and GoDaddy hosting changes should happen only after the new site is reviewed and approved.
